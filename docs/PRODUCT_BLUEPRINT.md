# Fluento Product Blueprint

## 1) Product Positioning
Fluento is designed as a **private Oxford coach + Silicon Valley AI assistant + chess-like skill progression system**.

### Core emotional outcome
Users should feel:
- More articulate each day
- Quantifiably stronger week-over-week
- Professionally powerful in high-stakes communication

## 2) Experience Pillars
- **Luxurious:** elegant dark visuals, smooth transitions, premium microcopy.
- **Minimal:** fewer but deeper interactions.
- **Smart:** AI diagnoses weak signals and prescribes exact drills.
- **Powerful:** performance dashboards and progression mechanics.
- **Data-driven:** confidence metrics, hesitation trends, writing complexity curves.
- **Addictive:** ELO-style ranking, tournaments, streak loops.

## 3) Feature System (v1)

### A. AI Speaking Coach (Real-Time)
Input: user live speech stream.

Detect:
- Pronunciation defects (phoneme-level)
- Grammar and syntax errors
- Lexical weakness / repetition
- Filler ratio and hesitation windows

Output:
- Instant corrective suggestion
- Native-like rephrase
- Confidence score
- Session fluency delta

Modes:
- British accent
- American accent
- Indian neutral accent
- Business English mode

### B. Fluency Rating Engine (0–3000)
Metrics:
- Speaking rating
- Writing rating
- Vocabulary rating
- Grammar rating
- Confidence index

Rating gain sources:
- Challenge completion
- Debate wins
- Daily consistency streaks
- Mock interview performance

Social competitiveness:
- Global leaderboard
- Country ranking
- Friends challenge mode
- Monthly tournaments

### C. Elite Vocabulary Builder
- Smart spaced repetition with adaptive review intervals.
- Domains: Business, Debate, Academic, Casual, Elite C2+.
- Word card anatomy:
  - definition
  - 3 high-quality examples
  - synonyms + opposites
  - conversation usage challenge
  - memory anchor

### D. AI Debate & Interview Simulator
Practice types:
- Debate match
- Job interview
- College admission interview
- Presentation rehearsal

AI scoring:
- Confidence
- Argument strength
- Vocabulary sophistication
- Professionalism

### E. Writing Master Lab
Analyze:
- Grammar accuracy %
- Vocabulary richness %
- Sentence complexity
- Formality fit
- Clarity

AI actions:
- Rewrite (advanced)
- Rewrite (native-like)
- Rewrite (elite)

### F. Pronunciation Perfection Mode
- Word-by-word drill mode
- Mouth animation guidance (3D later)
- Voice waveform alignment
- Accent reduction path
- A/B compare: user vs native model

### G. Real-Life Scenario Training
Scenarios:
- Airport
- Business meeting
- Public speech
- Debate competition
- Interview
- Classroom presentation
- Podcast guest

Difficulty is dynamic and tied to confidence volatility.

### H. Elite Communication Academy
Tracks:
- Public Speaking Mastery
- Business Communication
- Debate Champion Program
- Interview Cracker
- Accent Mastery
- Advanced Grammar Ninja

Each includes levels, unlock logic, certificate, and final AI exam.

## 4) Personalization & Intelligence Loop
1. Observe weak signals (hesitation spikes, grammar drift, pronunciation clusters).
2. Generate daily personalized plan.
3. Increase challenge difficulty progressively.
4. Detect plateau and switch strategy (e.g., debate-heavy week).
5. Tailor vocabulary by profession/interests.

## 5) Premium Monetization
Free tier:
- Limited daily sessions
- Basic correction
- Restricted vocabulary set

Premium tier:
- Unlimited speaking analysis
- Full debate + interview simulation
- Full writing lab and leaderboards
- Advanced analytics and accent controls

Plans:
- Monthly
- Yearly (discount)
- Lifetime Elite
- Student
- Corporate

Premium personas:
- Pro Speaker Mode
- CEO Communication Mode
- Oxford Elite Mode

## 6) Advanced Analytics Surface
Track and visualize:
- Weekly improvement graph
- Confidence growth trend
- Words mastered
- Speaking speed
- Hesitation reduction
- National benchmark comparison

## 7) Technical Architecture (Mobile)
Platform:
- React Native (Expo) for iOS + Android delivery

Core services:
- Real-time speech recognition pipeline
- LLM-based correction/rewrite engine
- Pronunciation scoring model (phoneme + stress)
- Adaptive recommendation engine
- Cloud profile and history store

Security and trust:
- Secure login (OAuth + email)
- Data encryption in transit and at rest
- Fine-grained user controls for voice data retention

## 8) Future Expansion
- Multi-language coaching
- Celebrity-style conversation simulations
- AI podcast practice mode
- Offline downloadable lesson packs
- AR-guided speaking mode

## 9) Psychology Design Engine
- Emphasize visible growth (“+3.2% this week”).
- Reward discipline with streak-protected incentives.
- Use high-status titles (Language Grandmaster 2500+).
- Trigger intelligent notifications based on behavior patterns.
